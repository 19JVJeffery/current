# Current

A modern app updater utility for macOS. Current is an open-source fork of [Latest](https://github.com/mangerlahn/latest) (created by [Max Langer](https://max.codes/latest/)) that checks if your apps are up to date. Get a quick overview of which apps changed and what changed and update them right away. Current currently supports apps downloaded from the Mac App Store and those that use Sparkle for updates.

If you have an idea for a new feature or encounter any bugs, feel free to open an issue in the [Issues](https://github.com/19JVJeffery/current/issues) section.

![Current][image-2]

## Build from Source

You can build Current directly on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/19JVJeffery/current.git
   ```
2. Open `Current.xcodeproj` in Xcode.
3. Select the `Current` scheme and hit **Product > Build** (or `Cmd + B`).
